# 共享引用标记的解除与延后清理

## 用户可见行为

从 DSH 移除未发送引用或删除已提交引用时，Obsidian 对应的插件定位标记在没有其他使用方时清除。有效引用、已提交回链、正在选择的引用，以及未删除的笔记／会话关联都算使用方。删除关联后留下的历史记录不占用标记。

仍有使用方时保留标记。最后一个引用或关联解除后，自动重试清理。笔记正文和用户已有的块 ID 保留；只有有插件创建记录的标记进入清理队列。

## 实现

- `VaultKnowledgeStore.referencesBlock` 排除已删除关联，并保护所有带块定位的有效关联。
- Companion 的 `data.json` 增加可选 `ownedMarkers`，只记录 `notePath` 和 `blockId`。它和待投递引用一起保存，在引用记录消失后保留清理责任；不复制正文或新增上下文快照。
- 选区直接创建会话贴纸的路径也保存标记归属，取消选择时仍保护其他占用者。
- 引用移除、回链删除、关联更改、知识同步及插件重新加载时尝试清理。写入失败或定位有歧义时保留记录以便重试；清理成功后删除记录。
- 写入笔记前再核对活动关联及未完成选择。原笔记仍存在但标记已消失时，不到其他笔记删除同名标记。
- 兼容旧 `dataVersion: 2`，已有待投递记录中的插件归属会补入队列。对于升级前已经丢失归属信息的孤立标记，不按名称猜测所有权。

## 验证与交付

类型检查、构建及全部 33 个测试文件、231 项测试通过。新增回归覆盖重启后延后清理、删除关联释放占用、写入失败重试、用户已有块 ID、同名块隔离、独占行标记及写入时出现新占用者。
