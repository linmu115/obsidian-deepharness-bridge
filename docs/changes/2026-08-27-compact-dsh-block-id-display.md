# 0.2.2 DSH 引用块标记紧凑显示

## 问题

Obsidian 为 DSH 引用写入的 `^dsh-note-*` 块 ID 会以很长的原始文本显示在笔记中，影响正文阅读，
但该 ID 又必须保留，才能稳定定位引用来源并完成清理。

## 修改

- 实时预览和阅读模式把插件生成、且位于行尾的 `^dsh-note-*` 显示为“DSH 引用”标签。
- 标签悬停提示保留完整块 ID，便于排错。
- 源码模式继续显示原始文本，底层 Markdown、引用协议和删除清理逻辑均未改变。
- 用户自建块 ID、普通正文和链接不参与替换。
- CodeMirror 依赖由 Obsidian 宿主提供，构建产物不重复打包编辑器运行时。

## 验证

- 标记匹配边界单元测试。
- TypeScript 类型检查、完整测试、生产构建和打包清单检查。
- 部署后确认 Bridge 健康端点正常，正式 Vault 的 `data.json` 保持不变。
