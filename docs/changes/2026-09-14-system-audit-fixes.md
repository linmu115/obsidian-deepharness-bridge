# Obsidian 会话图谱审计修复

对应系统审计 F07、F08、F09，版本 0.6.4-rc2.5。此记录描述代码与合成验证；运行副本的安装和验收另见系统交付报告。

## 功能与行为

- 编辑和阅读模式的选区菜单都增加“创建或挂接会话贴纸”，保留原“引用到 DSH”。新入口先展示工作区/会话，也可新建真实独立会话。它建立选段贴纸和双链，不自动发送模型请求。
- 贴纸保存稳定 Vault/笔记/块身份、受限选段、选段摘要和真实会话 ID。完整笔记正文不进入新增知识登记。共享类型沿用 Maintenance contracts。
- 先持久登记本地写入意图，再完成笔记回链、Maintenance 知识链接和贴纸写入。中断后重试复用同一对象，不重复建会话/贴纸版本，不复活已经删除的贴纸。取消未保存的选择会释放其标记；已被会话贴纸占用的块不再被普通待发送引用清理。
- 旧 Annotation 的打开来源继续使用现有 open-note 协议，服务端按块索引核对所有候选路径。移动、改名或旧路径被另一笔记占用时可找到真实来源；重复块标识或来源消失时明确失败，不猜测替代笔记。
- 删除与改名事件都登记同步需求。链接同步保存每条确认后的游标，一批最多 60 条，自动继续。中断/重载后从未确认位置恢复，超过 600 条也能推进；遍历期间发生的前段变更会触发下一遍核对。
- 同步批次和选段/整篇笔记选择器固定内嵌页来源，窗口切换不能把旧操作写入另一实例。知识写入串行协调；本地链接修订校验拒绝过期同步页。Maintenance 链接无变化时不重复追加版本。

## 验证

全量单元/组合测试 32 文件、217 项通过；类型检查及发布构建通过。原始输出保存在 `D:/AI/DeepSeekHarness-Plugin/artifacts/system-fixes-20260914/logs/obsidian-deepharness-bridge-exec.log`。

新增场景包括：650 条跨批次和重启续传；中途失败重试；遍历期间删除后再次扫描；过期同步页不得覆盖新删除；编辑/阅读两类选段菜单；选段意图重载、重复确认和独立删除；改名/移动/路径复用、重复块与缺失来源。沿用现有 200 多项引用、领取、持久回执和生命周期测试。

测试只使用合成笔记和会话，没有迁移真实 Vault，也没有调用真实模型。真实 Obsidian 内嵌页的点击与实际模型应答须结合安装后的使用验收；不能由测试数量推定。
