# 0.3.21 — DSH 0.1.2-alpha.1 compatibility record

## Upstream breaking changes

- `dsh web` now emits a process-specific one-shot token URL.
- An unauthenticated request returns 401; exchanging the token returns a 303 and an authentication cookie.
- The token rotates whenever DSH restarts, and the redirect discards sibling query parameters.

## Bridge changes

- Read the newest official DSH launch URL from the configured launch log instead of persisting a bearer token.
- Validate the loopback origin and reauthenticate the Obsidian Web Viewer after DSH restarts.
- Open the viewer in explicit Obsidian `webview` mode and reuse it by loopback origin.
- Store the dedicated surface identity in the redirect-safe URL fragment, then pre-provision each viewer once.
- Queue reference and sticker navigation only after the target surface owns the action, preventing reload loops and cross-browser action theft.
- Keep managed reference and sticker backlinks compact in Obsidian while preserving the original logical target and deletion lifecycle.

Bridge is an Obsidian companion artifact, not a DSH profile bundle. It is tracked by Maintenance as an external companion.
