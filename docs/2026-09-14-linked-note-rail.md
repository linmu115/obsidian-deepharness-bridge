# 会话页关联笔记气泡与按需引用

关联成功后，当前会话输入区域显示常驻的关联笔记气泡。点击气泡展开两个明确入口：在 Obsidian 打开对应笔记/块；引用到本轮。Obsidian 中已有的会话链接继续进入 DSH 完整会话，两个方向均保留。

关联只保存关系，首次显示气泡不读取笔记正文，不自动发送消息。只有用户点击引用时才准备当前笔记材料、加入 Annotation Core 待发送引用，并在 Companion 保存绑定实例/会话/引用集的回执。此路径不进入自动领取队列，因此其它窗口不会抢走引用。读取或保存失败会显示错误；已加入的失败引用通过 Core 操作撤销接口处理。

来源笔记按稳定 noteId 解析。选段引用必须仍能定位到唯一来源块；原选段变化、块丢失/重复、关联解除、实例/会话/profile 不一致均拒绝。无选段的笔记关联使用短预览及当前笔记正文，超过传输预算时要求回到 Obsidian 选段。准备记录只短暂存在内存，只有显式加入本轮时使用现有引用存储，不新增逐轮全库快照。

气泡通过原生 conversation.input.dock 插槽挂载，跟随会话与输入框布局；使用 DSH 主题色。可水平滚动，链接分页按用户展开范围刷新。页面隐藏时暂停轮询，卸载时清除定时器和监听。打开或切换会话不自动引用或调用模型。

## 验收

1. 建立关联后无需打开贴纸面板，在当前会话看到气泡；其它会话不出现此关联。
2. “在 Obsidian 打开”定位原笔记/块，Obsidian 侧链接仍能返回完整会话。
3. “引用到本轮”出现 Annotation 待发送气泡，保留原草稿，未发送前不调用模型。
4. 切换会话、来源变更、解除关联、重复操作及失败补偿受到校验。
5. 升级后已有笔记、关联、会话历史保持不变。
